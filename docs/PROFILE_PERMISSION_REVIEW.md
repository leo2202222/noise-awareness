# รายการสิทธิ์ที่รออนุมัติ — ยังไม่ได้ใช้งาน

ผลทดสอบ Cloud 4.4.1PAAS: Customer User ที่สร้างใน USER group ส่วนตัวเปลี่ยนรหัสผ่านผ่าน POST /api/auth/changePassword ไม่ได้ (403) เพราะไม่มี PROFILE WRITE

ข้อเสนอให้พิจารณา: สร้าง GENERIC role เฉพาะ PROFILE READ และ WRITE แล้วผูกกับ USER group ส่วนตัวของผู้สมัครแต่ละคน โดยไม่เพิ่มสิทธิ์ USER, CUSTOMER, DEVICE หรือ TENANT และไม่ผูกกับ All users

Payload role ที่เสนอ:

```json
{"name":"NAS own profile","type":"GENERIC","permissions":{"PROFILE":["READ","WRITE"]}}
```

ขั้นตอนหลังได้รับอนุญาตเท่านั้น: ตรวจ schema/API ของ instance อีกครั้ง สร้าง role ข้างต้น ผูก group permission กับ USER group ส่วนตัว ทดสอบเปลี่ยนรหัสผ่านบัญชีชั่วคราว และยืนยันว่าแก้บัญชีคนอื่น/อุปกรณ์ที่ไม่ได้รับมอบหมายไม่ได้ หากทดสอบไม่ผ่านให้ลบ grant และ role ที่เพิ่งสร้าง

โค้ดปัจจุบันยังไม่สร้างหรือมอบ role นี้ การทดสอบใช้สิทธิ์เดิมของ Cloud และรายงานข้อจำกัดตรงตามจริง
ระบบอนุมัติอัตโนมัติปฏิเสธการเปลี่ยนแปลงนี้เพราะเพิ่มขอบเขตสิทธิ์ถาวรแก่ผู้สมัครใหม่ทุกคนโดยยังไม่ได้รับอนุญาตชัดเจน ต้องได้รับคำยืนยันก่อนดำเนินการ
